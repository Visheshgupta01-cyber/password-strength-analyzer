# Password Strength Analyzer

## Project Overview

The Password Strength Analyzer is a Python-based cybersecurity application that evaluates password strength and provides security recommendations to users.

## Features

* Password strength detection
* Security score calculation
* Password entropy estimation
* Secure password generation
* Copy password functionality
* Password visibility toggle
* Security tips and recommendations
* User-friendly graphical interface

## Technologies Used

* Python
* Tkinter
* Math module
* Secrets module
* String module

## How to Run

1. Install Python on your computer.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run the following command:

```bash
python password_gui.py
```

## Purpose

The purpose of this project is to promote password security awareness and help users create stronger passwords.
